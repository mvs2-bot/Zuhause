Mit Home Assistant verbinden

Die App spricht direkt mit deinem Home Assistant auf dem Pi, über Tailscale. Dafür braucht sie einmalig ein Zugriffstoken.

  1. Tailscale auf diesem Gerät einschalten.
  2. Home Assistant öffnen → unten links dein Profil → Reiter Sicherheit → Langlebige Zugriffstoken → Token erstellen, Name z. B. „Zuhause-App Handy“.
  3. Token kopieren und unten einfügen.
